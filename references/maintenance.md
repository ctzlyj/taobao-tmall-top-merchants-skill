# 安装同步、上游合并与回滚

源码仓库是维护入口，运行时安装目录可能包含独有文件、任务数据及本地修改。禁止 `reset --hard`、整目录覆盖或删除式同步。

先检查安装路径是否是Junction或符号链接。若已解析到同一源码目录，代码修改已经生效，不执行复制到自身；仍需从安装路径运行验证并记录实际目标，避免误以为存在两份独立副本。

## 三方基线

本轮开发基线为仓库提交 `6d649ff13ffe8dabb13db70a6a9edd562bbdeaa7`。同步记录必须保存基线提交、每个文件的源/安装SHA-256、原文件备份路径和应用结果。Git规范化blob哈希用于识别仅换行差异；安装后仍按字节SHA-256核对。

同步前逐文件比较基线、当前源码、安装版：

- 安装版等于基线、源码有更新：备份原文件后同步。
- 源码与基线相同、安装版有修改：保留安装版，不覆盖。
- 两边相同：无需处理。
- 两边都相对基线有修改且互不相同：停止覆盖，暂存上游候选，完成语义合并和回归测试后再同步。
- 安装版独有文件及 `work/`、输出、凭证配置、`.git/` 不同步、不删除。

上游有新版本时，将该版本作为候选输入，不能直接把安装目录恢复成上游。保留本地回归场景，合并后重新运行整个测试集，再应用安装更新。

## 验证与回滚

源码与安装版分别运行 `python -B -m unittest discover -s tests -v`。校验新增脚本/参考文件存在、安装文件哈希与已验证源文件一致。代码升级并不授权真实采集、上传、提交或推送。

回滚逐文件恢复同步前备份；保留新格式任务证据。审核v1检查点在 `.v1.bak` 中保留，新v2检查点不能由旧代码误读。企业验证数据与原业务任务隔离存放，不为了回滚删除已取得证据。

## 网页默认入口与联系人升级

触发问题：Skill写明默认网页，但旧 `enterprise_pipeline.py --execute` 仍加载付费Provider，旧预检默认读取/验证企业Key；网页联系人规则仅有文字、未进入可复用的结构化交付。根因是业务路由与执行入口分离，不是需要更换全部浏览器工具。

当前行为：入口默认网页，付费模式和旧直调CLI都有显式开关；默认预检只做本地检查。`browser_enterprise.py` 复用站点适配器，不复制DOM解析；`browser_contacts.py` 按号码、公司、最小原文和时效处理联系人证据，法人不推定号码使用人。Router负责按需选工具、现有登录和任务后台页，不强制O2或独立Profile登录。

回归命令：

```text
python -X utf8 -B -m unittest discover -s tests -v
node --test <风鸟适配器目录>/company.test.js
node tests/browser_fixture_smoke.mjs <已有Playwright运行根目录> <风鸟适配器目录>/company-core.js <隔离输出目录>/browser-fixture.json
```

模拟网页验证使用独立无头Chrome并拦截全部页面请求，不复用个人Profile、不接触真实商家网站；覆盖页脚客服排除、掩码、明确无记录、登录、验证码、付费、未知结构及主体冲突。输出可继续送入业务执行器验证联系人和缓存衔接。这些测试不能证明当前企查查登录、搜索解析、网页接口、真实批量稳定性或号码本人身份。

成功记录缓存与当前检查点分开，避免前序目标变更暂停后覆盖后续已成功记录。新增 `browser_cache.json`、`browser_checkpoint.json` 不写入旧API的双源结果文件；回滚保留业务证据，先停止新执行路径，不通过撤掉付费保护来恢复查询。任何回滚只恢复本次变更，不能覆盖原有未提交修改。网站身份、权限、验证码或返回结构变化时停止对应动作，先重新验证适配器，不用手改成功标记绕过。

## 爱企查来源接入

补齐原入口没有爱企查来源和受限处理指南的问题；新增 `references/aiqicha-web.md` 并接入Skill、网页流程及README。复用既有 `browser_contacts.contact_rows` 的多来源联系人证据语义，不改风鸟域名校验、不安装MCP、不修改付费开关。受限页不能证明未披露，HTTP 200不能证明企业详情已查到。

初次入口出现调试窗口提示；复测BrowserSkill同样附加调试协议，原指南把工具兼容问题与权限门禁合并停止，范围过宽。正常安装Chrome的原生无调试连接模式已实测可读公开首页，但同一任务Profile的企业搜索触发百度安全验证，未取得企业详情或新号码。现分别记录兼容恢复与搜索门禁；不默认让用户整理截图，不将未验收的搜索/详情解析沉淀为可用适配器，不为后续目标重复触发验证。

`tests/test_aiqicha_web.py` 覆盖路由、网页/API隔离、门禁、逐号码来源保留、联系人冲突、法人误认及敏感URL。文字契约测试不能替代现场验证；首页可读、搜索尝试、详情完成分别留回执，来源策略维护与真实企业查询的验收范围分别报告。能力新增不是额外拨号、发消息或付款授权；回滚仅恢复此次指导文字并保留查询回执，不覆盖其他未提交修改。
